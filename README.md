# Dental_POC

> Frontend Proof of Concept (POC) for **Dr. Bhatti & Associates (Prestigious Family Dental)** built with Laravel 12, Tailwind CSS v4, and Vite 8.

---

## Overview

This project explores and contrasts two distinct, high-fidelity frontend design directions within a single cohesive Laravel application:

- **Variant A (Expressive / 2D Cutout)**: Warm stone surfaces, layered 2D cutouts, illustrative compositions, and purposeful settled entrance motion.
- **Variant B (Calm / Editorial)**: Restrained architectural typography, generous negative space, natural photography, and soft fluid transitions.

Both variants share an identical clinical Information Architecture (copy, doctor credentials, treatment landscape, and patient journey steps) to ensure pure design comparison.

## Getting Started

### Prerequisites
- PHP 8.3+
- Composer
- Node.js & npm

### Setup
```bash
# Clone the repository
git clone https://github.com/Zeeshan506/Dental_POC.git
cd Dental_POC

# Install PHP dependencies
composer install

# Install Node dependencies
npm install

# Start development servers
npm run dev
php artisan serve
```
